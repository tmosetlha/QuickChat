QuickChat
​A Java-based authentication and messaging application featuring user registration, login management, and unit testing setup.  
​Features
​User Registration: Handles user account creation and data validation.  
​Login System: Authenticates existing users.  
​Unit Testing: Integrated JUnit test suites for validating core registration and login logic.  
​Maven Build Management: Managed dependencies and project builds via Maven (pom.xml).

QuickChat/
├── Login.java          # Core login functionality
├── LoginTest.java      # JUnit unit tests for Login
├── QuickChat.java      # Application entry point / main class
├── Register.java       # User registration implementation
├── RegisterTest.java   # JUnit unit tests for Register
└── pom.xml             # Maven configuration file
